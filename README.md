# VS2026 Handbook — Chapter 9

This repository contains Python examples for Chapter 9 of the *VS2026 Handbook*. The examples demonstrate SQLite database operations, including creating tables, inserting records, querying data, updating entries, and summarizing balances.

## Contents

- `customers.py` — customer data and database operations.
- `customers.db` — SQLite database used by the examples.
- `customer_balances_summary.py` — summarize customer balances.
- `python search_customer.py` — search for customer records.
- `example9.4.py` through `example9.7.py` — Chapter 9 examples.
- `sqlite_products.py` — work with product records in SQLite.
- `sqlite_update.py` — update records in a SQLite database.
- `VS2026HandbookChapter9.py` — main Python example script.
- `VS2026HandbookChapter9.pyproj` / `VS2026HandbookChapter9.slnx` — Visual Studio project files.

## Requirements

- Python 3
- Visual Studio 2026 or a Python-compatible editor

SQLite support is included with Python through the standard-library `sqlite3` module.

## Run

Open `VS2026HandbookChapter9.slnx` in Visual Studio or run an individual script from the repository directory:

```bash
python VS2026HandbookChapter9.py
```

Replace the filename above with another example script as needed.
